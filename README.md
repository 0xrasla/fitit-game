# Inkstinct

A fast Stroop-effect color reflex game built with Flutter.

Tap the color of the text — not the word itself!

## Build

```bash
cd app
flutter build appbundle
flutter build apk --release
```

## Tech Stack

- **Framework:** Flutter / Dart
- **Audio:** Flame / Flame Audio
- **Ads:** Google Mobile Ads (AdMob)
- **Storage:** SharedPreferences
- **Sound FX:** Procedurally generated 8-bit WAV
